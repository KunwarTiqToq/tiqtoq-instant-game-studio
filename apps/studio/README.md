# Game studio application

The three PixiJS games live here. Use the repository root for setup and combined startup:

```powershell
npm run setup
npm start
```

From this directory, `npm start` also launches both applications; `npm run dev` launches just the frontend, and `npm run build` builds the studio into `dist/`. Dependencies and the lockfile belong to the repository root.

See [root README](../../README.md), [game configuration](../../docs/configuration.md) and [asset credits](../../docs/asset-credits.md). Original MIT notices are retained in LICENSE.
